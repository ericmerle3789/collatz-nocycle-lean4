### 2.2 `Phase61CFConvergents.lean` (~100-150 lignes)

**Responsabilité** : calculer explicitement les convergents `q_0, q_1, ..., q_14` de la CF de `log_2 3`, lier aux valeurs numériques utilisées dans Phase59 (`665`, `15601`, `31867`, `79335`, `111202`, `190537`, `10590737`), et fournir une interface `q : ℕ → ℕ`.

**Challenge principal (R-M3.2)** : `Real.convergent` est `noncomputable` car `Real.logb 2 3` est noncomputable. On ne peut pas simplement faire `#eval (Real.logb 2 3).convergent 8`.

**Stratégie** : calculer les convergents sur une **approximation rationnelle** de `log_2 3`, et prouver que ce sont les *vrais* convergents via la caractérisation de Legendre appliquée à l'inverse. Alternative : définir directement les convergents en `ℕ → ℕ × ℕ` (pair p_n / q_n) via la récurrence CF standard appliquée aux coefficients `a_n` connus de `log_2 3`.

**Option retenue (discussion M2.4)** : coefficients CF pré-calculés de `log_2 3` :
```
log_2 3 = [1; 1, 1, 2, 2, 3, 1, 5, 2, 23, 2, 2, 1, 1, 55, 1, 4, ...]
```
Calculer `p_n / q_n` via la récurrence Euclide :
- `p_{-1} = 1, p_0 = a_0`, `p_n = a_n · p_{n-1} + p_{n-2}`
- `q_{-1} = 0, q_0 = 1`, `q_n = a_n · q_{n-1} + q_{n-2}`

Avec les `a_n` de `log_2 3`, on obtient :
```
q_0 = 1, q_1 = 1, q_2 = 2, q_3 = 5, q_4 = 12, q_5 = 41, q_6 = 53, q_7 = 306, q_8 = 665, q_9 = 15601, q_10 = 31867, ...
```

(Note : ces valeurs correspondent aux qn mentionnés dans Phase59. Vérifier via OEIS A028507 ou calcul indépendant.)

**Contenu** :

