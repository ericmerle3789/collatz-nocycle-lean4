### Analyse

Le résultat est mathématiquement élémentaire. Esquisse de preuve Lean :

```lean
lemma irrational_logb_two_three : Irrational (Real.logb 2 3) := by
  rw [Irrational]
  intro ⟨q, hq⟩
  -- hq : Real.logb 2 3 = q
  -- Donc 2 ^ q.num = 3 ^ q.den (en prenant 2^(·)) après manipulation
  -- 2^q.num est un entier pair (si q.num > 0), 3^q.den est un entier non-divisible par 2
  -- Contradiction via Nat.Prime.pow_dvd_iff ou similaire
  sorry  -- preuve complète : ~20-30 lignes avec Mathlib Nat.factorization
```

### Estimation coût M3

~20-30 lignes, routine. **Module `Phase60IrrationalityLog23.lean` estimation confirmée**.

## 4. M2.2c — Notation mapping paper ↔ Mathlib

### Paper notation

- `q_i` = dénominateur du i-ème convergent de la CF expansion de `log_2 3`
- Table paper (Phase59 docstrings) : `q_6 = 665`, `q_7 = 15601`, `q_8 = 16266`, ..., `q_13`

### Mathlib notation

Mathlib a **deux représentations équivalentes** des convergents (pont via `Real.convs_eq_convergent`) :

#### Option A : `Real.convergent` (recommandée M3)

```lean
noncomputable def Real.convergent : ℝ → ℕ → ℚ
  | ξ, 0 => ⌊ξ⌋
  | ξ, n + 1 => ⌊ξ⌋ + (convergent (fract ξ)⁻¹ n)⁻¹
```

Renvoie directement un `ℚ`. Pour le dénominateur `q_i` :
```lean
def q_log23 (i : ℕ) : ℕ := (Real.logb 2 3 |>.convergent i).den
```

Avantage : définition **récursive** compatible `native_decide` via `Rat.den`.

#### Option B : `GenContFract.of ξ |>.convs`

```lean
(GenContFract.of (Real.logb 2 3)).convs n : ℝ
(GenContFract.of (Real.logb 2 3)).convs' n : ℝ
```

Renvoie un `ℝ` (vers projet contre). Moins adapté à notre cas car on veut `ℚ`.

Mathlib prouve `(GenContFract.of ξ).convs n = ξ.convergent n` (pont `convs_eq_convergent`), donc les deux coïncident.

### Recommandation M3

**Utiliser `Real.convergent`** (Option A), par cohérence avec le usage de Legendre theorem qui l'invoque directement (`Real.exists_rat_eq_convergent`). Simplifie l'import : un seul `import Mathlib.NumberTheory.DiophantineApproximation.Basic` suffit.

Mapping paper ↔ Lean :
- `q_i` du paper ↔ `(Real.logb 2 3).convergent i |>.den` (type `ℕ`)

Pour les valeurs numériques spécifiques (e.g. `q_6 = 665`) : à prouver via `native_decide` ou direct calcul dans `Phase61CFConvergents.lean`.

## 5. Mesure d'irrationalité (M2.1 follow-up)

Confirmé : `LiouvilleWith p x` existe (`Mathlib.NumberTheory.Transcendental.Liouville.LiouvilleWith`) mais pas de résultat quantitatif pour `log_2 3`.

### Stratégie M3

**Option 1** : Hypothèse structurelle `RhinBound` analogue à `BakerSeparation` :
```lean
structure RhinBound where
  rhin_log23 : ∀ (p q : ℤ), 0 < q → |Real.logb 2 3 - (p : ℝ) / q| ≥ (1 : ℝ) / (q : ℝ) ^ (6 : ℕ)
```
(avec `μ = 6`, plus simple que Rhin 5.125 mais suffisant).

Référence : Rhin 1987, publié dans *Progrès en Mathématiques*.

**Option 2** : dériver via `BakerSeparation` (notre hypothèse existante) + algèbre élémentaire.

**Recommandation** : Option 1 pour cohérence avec `BakerSeparation` style. 3e hypothèse structurelle publiée, intégrité préservée.
