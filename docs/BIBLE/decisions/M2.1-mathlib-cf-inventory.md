## 1. Résumé exécutif

**Mathlib a une infrastructure CF mature. Legendre's best-approximation theorem est déjà formalisé dans Mathlib** sous le nom `Real.exists_rat_eq_convergent`. Cela retire la barrière technique principale anticipée pour M3 : nous n'avons PAS besoin de formaliser Legendre from scratch.

**Findings principaux** :
- ✅ `Mathlib.Algebra.ContinuedFractions.Basic` — définitions CF + convergents
- ✅ `Mathlib.NumberTheory.DiophantineApproximation.Basic` — Legendre (two versions) + Dirichlet
- ✅ `Mathlib.NumberTheory.DiophantineApproximation.ContinuedFractions` — pont GenContFract / Real.convergent
- ✅ `Real.logb` / `Real.log` — définitions de `log_2 3 = Real.logb 2 3`
- ✅ `LiouvilleWith` / irrationality exponent concept — base théorique
- ❌ Irrationalité de `log_2 3` **non explicitement formalisée** dans Mathlib (lemme à prouver ou hypothéser)
- ❌ Mesure d'irrationalité de `log_2 3` (Rhin 1987 : μ ≤ 5.125) **non formalisée** — à poser comme hypothèse structurelle analogue à BakerSeparation
- ❌ Convergents spécifiques `q_8, q_9, ..., q_13` de `log_2 3` — calculables via `native_decide` mais pas présents as-is

**Impact sur plan M3** : plan faisable, mais moins "replace structure by theorem" que "combine Mathlib Legendre + structural hypothesis for Rhin bound + computational convergents". Voir §6.

## 2. Modules Mathlib examinés

### 2.1 `Mathlib.Algebra.ContinuedFractions.*` (13 fichiers)

Contenu : définitions de continued fractions (generalised, simple, regular), computation via recurrence, convergents `convs`, convergents via direct evaluation `convs'`, translations, determinant identities, termination.

Fichiers clés :
- `Basic.lean` : `GenContFract`, `convs`, `convs'`, `ContFract` (regular CF)
- `ConvergentsEquiv.lean` : équivalence `convs = convs'`
- `Computation/ApproximationCorollaries.lean` : corollaires d'approximation pour CF d'un réel
- `Computation/Basic.lean` : construction de la CF d'un réel via floor + fract

### 2.2 `Mathlib.NumberTheory.DiophantineApproximation.*`

- `Basic.lean` : Dirichlet approximation + **Legendre's theorem** + `Real.convergent` (simple recursive def)
- `ContinuedFractions.lean` : pont entre `Real.convergent` et `GenContFract.of ξ |>.convs`

### 2.3 `Mathlib.Analysis.SpecialFunctions.Log.*` (11 fichiers)

Contenu : `Real.log`, `Real.logb`, dérivées, monotonicity, asymptotics.

Pas de lemmes spécifiques à `log_2 3` par nom ; Mathlib traite `Real.logb` pour base et argument généraux.

### 2.4 `Mathlib.NumberTheory.Transcendental.Liouville.*`

Contenu : Liouville numbers, `LiouvilleWith p x` (irrationality exponent au sens "pour une infinité de p/q on a |x - p/q| < C/q^p"), lemmes sur les nombres transcendants.

**Concept mais pas de bounds explicites** pour `log_2 3` spécifiquement.

## 3. Lemmes pertinents existants — catalogue

### 3.1 Legendre's theorem (LE LEMME CENTRAL)

```lean
-- Mathlib/NumberTheory/DiophantineApproximation/Basic.lean:538
theorem Real.exists_rat_eq_convergent {ξ : ℝ} {q : ℚ}
    (h : |ξ - q| < 1 / (2 * (q.den : ℝ) ^ 2)) :
    ∃ n, q = ξ.convergent n
```

**Statement** : si `|ξ - q| < 1/(2 q_den²)`, alors `q` est un convergent de ξ.

**C'est exactement le théorème de Legendre 1798** dont M3 a besoin.

### 3.2 Version alternative via GenContFract

```lean
-- Mathlib/NumberTheory/DiophantineApproximation/ContinuedFractions.lean
-- (pont via GenContFract.convs)
```

Mêmes propriétés, via l'autre formulation des convergents.

## 4. Gaps identifiés (lemmes nécessaires mais absents de Mathlib)

### 4.1 Irrationalité de `log_2 3`

**Besoin M3** : `Irrational (Real.logb 2 3)` pour pouvoir appliquer Legendre (qui requiert un réel avec approximations CF non-terminales).

**Statut Mathlib** : concept `Irrational : ℝ → Prop` existe (`Mathlib.NumberTheory.Real.Irrational`), mais pas de lemme spécifique pour `Real.logb 2 3`.

**Solution M3** :
- **Option A** : prouver `Irrational (Real.logb 2 3)` en Lean (preuve classique : si rationnel, alors `3^q = 2^p` pour entiers p, q, impossible par unique factorization). Estimation : 30-50 lignes de Lean.
- **Option B** : poser comme hypothèse structurelle (comme BakerSeparation). Mais c'est un résultat élémentaire, devrait être prouvé.

**Recommandation** : Option A, ajouter un petit module `Phase60IrrationalityLog23.lean`.

### 4.2 Mesure d'irrationalité effective de `log_2 3` (Rhin 1987)

**Besoin M3** : bound effectif `|log_2 3 - p/q| ≥ c / q^μ` pour μ = 6 (notre choix) ou μ = 5.125 (Rhin, plus fin).

**Statut Mathlib** : `LiouvilleWith p x` existe, mais pas de résultat quantitatif sur `log_2 3`.

**Solution M3** :
- Hypothèse structurelle `RhinBound` analogue à `BakerSeparation` (les deux sont publiés 1966 + 1987, peer-reviewed).
- **OU** : dériver la Rhin bound à partir de Baker (plus coûteux formellement, car Baker bound est déjà structurelle dans notre repo).

**Recommandation** : poser `RhinBound` comme nouvelle hypothèse structurelle, cohérente avec BakerSeparation. Le paper v2 aurait alors **2 hypothèses publiées** (Baker + Rhin + Barina = 3 publiées) au lieu des 2 actuelles.

Alternative architecture : garder uniquement `BakerSeparation` avec μ=6 (évite Rhin), prouver DerivedLargeKBound directement via Baker + CF Mathlib. Scope M3 réduit.

### 4.3 Convergents spécifiques `q_i` de `log_2 3`

**Besoin M3** : valeurs spécifiques `q_8 = 665`, `q_9 = 15601`, ..., `q_13` pour le raisonnement windowing.

**Statut Mathlib** : pas de table de convergents pour `log_2 3` (comme attendu, c'est trop spécifique).

**Solution M3** : calculer via `native_decide` en Lean (les `q_i` sont des entiers, les récurrences de convergents sont déterministes). Attendu : ~20-30 lignes. Mais **attention** : introduction de `Lean.ofReduceBool` + `Lean.trustCompiler` dans la chaîne centrale si ces valeurs sont utilisées en M3 pour prouver DerivedLargeKBound.

**Recommandation** : calculer les `q_i` dans un module dédié `Phase61CFConvergents.lean`, avec déclaration préventive dans `expected_axioms.md` (déjà prévue per paper §6.5 et commentaire M3).
