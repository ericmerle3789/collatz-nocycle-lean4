## 1. Scope and pivot rationale

Paper v2 replaces the earlier **Option α** (positive proof via Phase63 `DerivedLargeKBoundTheorem`) with **Option β renforcée**, a conditional proof that:

1. Presents the Phase58 central theorem rigorously (no new Lean theorems needed beyond what is already SIGNED in the repository).
2. Documents **three structural hypotheses** honestly :
   - `BakerSeparation` (Baker 1966, published linear forms in logarithms)
   - `BarinaVerification` (Barina 2025, published computational n < 2^71)
   - `ProductBoundThreshold` (project-derived, made explicit and justified in §4-§5)
3. Presents **five scientific contributions** (δ7, δ8, δ8', δ9, 6α) as originals of this work.
4. Maps the 1977-2026 state-of-the-art (Steiner, Crandall, Simons-de Weger, Hercher, Santana, Knight, Dhiman-Pandey, Rozier-Terracol).
5. Articulates *why* the current literature — ours included — does not close the general case, and *what* remains open.

The pivot is a scientific judgement : Session C's 11-branch tree exploration (2026-04-24) established that every product-bound approach is structurally limited to `k ≤ ~10^10` (§5 Obstruction I, δ8). Honest documentation of this limitation is itself a contribution.

See `docs/BIBLE/JOURNAL.md` M3.4 entry and `docs/BIBLE/mathnotes/2026-04-24-paper-v2-mathnotes-package-from-session-C.md` for the full provenance.
